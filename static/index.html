知阶 CogniScaffold · 新手使用与功能图解

不给答案，只给台阶 · 开启深度启发式探究之旅

1 核心理念：搭建最近发展区 (ZPD) 阶梯

知阶拒绝直接赠予最终答案或套路范文。系统扮演富有教育温度的苏格拉底认知导师，在你的推导断点处抛出反例检验、极值探讨或跨学科同构，引导你在自主探索中实现思维跃迁。

2 多元开题与全学科科学输入

• 文本录入：支持全学科 LaTeX 数学物理公式（用 $ 包裹），配备全学科悬浮 LaTeX 符号键盘。
• 拍照识别：支持上传草稿纸或试卷照片，AI 智能提取题目与手写推导步骤。
• 经典案例库：内置 22 套覆盖浙江新高考十科（数、物、化、生、技、语、英、政、史、地）及综合探究的金牌范例，一键载入体验。

3 启发式互动与沉浸对话

• 快捷发送：输入你的推导思路后，按 Ctrl + Enter 即可极速发送。
• 换个角度：遇到思维死胡同时，点击「💡 换个角度」，导师将从全新直观图景或简化特例重新启发。
• 看板折叠：点击右侧看板顶部的「收起看板」，界面自动居中并拓宽至全屏沉浸陪练模式；点击右侧边缘小箭头药丸随时恢复看板。

4 什么时候申请「思维突破与错因诊断」？

当你在导师启发下完成至少 3 轮推导、并给出自己的破题方案后，点击输入区下方的「🔍 申请思维突破与错因诊断」按钮。导师将核验你的推导漏洞，自动生成专属思维盲区画像，并解锁维度拓展、逆向对抗、跨界迁移的三阶变式同构挑战！

5 额度管理与防沉迷保底

• Token 额度：顶部导航栏实时展示 Token 剩余百分比（如 ⚡ Token 85%），覆盖会话、识图、画像等所有大模型消耗。
• 对话限额：单日题目数与单题交互轮次上限作为防沉迷保底，守护专注高效的学习节律。
